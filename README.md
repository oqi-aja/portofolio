# Portofolio & Showcase Repositori - oqi_tfkr

Dashboard portofolio personal dan etalase repositori GitHub untuk [@oqi-aja](https://github.com/oqi-aja).

## Fitur Utama

- **Dashboard Bento Modern**: Ikhtisar profil, statistik repo, dan stack teknologi utama.
- **Pencarian & Filter Interaktif**: Filter kategori (Desktop/Streaming, Web, TypeScript/Games) dan pencarian instan.
- **Showcase Repositori Riil**: Menghubungkan langsung ke repositori nyata seperti `drone-live-engine`, `StudentHub`, `puzzel-game`, `cartcup`, dll.
- **Aksesibilitas & UI/UX Standar**: Target sentuh 44px (WCAG 2.2), kontras tinggi, navigasi keyboard lengkap, dan SVG murni tanpa emoji.

## Cara Menjalankan

Buka file `index.html` langsung di browser, atau jalankan server lokal:

```bash
# Opsi Python
python -m http.server 3000

# Opsi Node.js
npx serve .
```

## Verifikasi Mandiri

```bash
node test-check.js
```
